# Ghi chú

Ca sử dụng: văn bản/rich text, ảnh, thư mục/tag, ghim, autosave, revisions và thùng rác.

Repository lưu nội dung JSON/schemaVersion và metadata; ảnh nằm ở Storage. Soát version tránh autosave ghi đè bản mới; khi lưu lỗi giữ nội dung nháp. OCR/AI là nâng cấp tùy chọn, không bật mặc định.
