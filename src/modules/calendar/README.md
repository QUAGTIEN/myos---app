# Lịch

Ca sử dụng: tạo/sửa lịch hẹn, thời khóa biểu lặp tuần, ngoại lệ, nhóm màu, đánh dấu, nhắc và xuất .ics.

Service điều phối lưu event/version và jobs; repository truy cập events/exceptions/reminders theo UID. Quy tắc thời gian/lặp đặt trong domain. UI tương tác FullCalendar đặt tại components khi triển khai.

Thay đổi một buổi/từ đây/toàn chuỗi cần hợp đồng rõ; không gửi Zalo trực tiếp trong action hay transaction.
